Compute mean/std for accuracy, f1_macro, f1_weighted from fold metrics. Also compute per-class metrics from the aggregated matrix (precision, recall, F1 per class). Return dict with: confusion_matrix, accuracy_mean, accuracy_std, f1_macro_mean, f1_macro_std, f1_weighted_mean, f1_weighted_std, per_class_metrics, test_set_size, n_folds, total_evaluations, per_fold_accuracies, best_fold, best_fold_accuracy.

2. `load_ensemble_tta_data(cv_dir)` — Load ensemble+TTA results from `ensemble_test_results_tta.json`. Extract: confusion_matrix from `ensemble_soft_voting.confusion_matrix`, metrics from `ensemble_soft_voting.metrics`, per_class from `ensemble_soft_voting.per_class`, tta_delta_metrics, case_level_analysis. Return structured dict.

**Confusion matrix plot function:**

`plot_confusion_matrix(cm, class_names, title, subtitle, output_path)` — Follow the pattern from `generate_confusion_matrix_cv.py` lines 108-215:

- Figure size: (12, 9)
- Row-wise normalization: `cm_percent = cm.astype('float') / cm.sum(axis=1)[:, np.newaxis] * 100`
- Use `sns.heatmap(cm_percent, annot=False, cmap='Blues', vmin=0, vmax=100)` with colorbar label "Porcentaje (%)"
- Custom dual annotations in each cell: `f'{value}\n({percent:.1f}%)'` — value is raw count, percent is row-normalized
- Text color: white if percent > 50, else black; bold on diagonal
- Font size for annotations: 15
- Axis labels in Spanish: "Predicción" (x), "Categoría Real" (y)
- Class display names: ["COVID-19", "Normal", "Neumonía Viral"]
- Title format: main title on first line, subtitle with metrics on second line
- For baseline: subtitle = `f'Promedio Individual (k=5) — Accuracy: {acc:.2f}% ± {std:.2f}%'`
- For ensemble+TTA: subtitle = `f'Ensemble + TTA — Accuracy: {acc:.2f}%'`
- `plt.savefig(output_path, dpi=300, bbox_inches='tight', facecolor='white')`

**Baseline title**: "Matriz de Confusión — Modelo Individual (Baseline)"
**Ensemble+TTA title**: "Matriz de Confusión — Ensemble + TTA"

**IMPORTANT differences from baseline vs ensemble+TTA confusion matrices:**
- Baseline confusion matrix is the SUM of 5 fold matrices (total_evaluations = 9,475). Title should note this.
