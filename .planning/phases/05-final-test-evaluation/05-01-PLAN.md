Create `scripts/evaluate_final_ensemble_tta.py` — a standalone script (NOT a CLI command) that performs the definitive evaluation. All human-readable console output in Spanish per user decision.

The script must implement these sections in order:

**1. Test Set Isolation Verification**
- Load training history from `outputs/classifier_cv/fold_01..05/training_history.json`
- Assert no key contains "test" in any epoch's metrics (only train/val allowed)
- Verify temporal separation: model checkpoint mtime < test results mtime (model files dated 2026-01-16)
- Verify config files in `outputs/classifier_cv/fold_*/` contain `eval_test: false`
- Print verification results in Spanish ("VERIFICACION DE AISLAMIENTO DEL CONJUNTO DE PRUEBA")
- If any check fails: print warning but continue (do not abort)

**2. Load Ensemble Models + Test Data**
- Load config from `configs/ensemble_classifier.json`
- Use existing `load_ensemble_models()`, `ensemble_inference_with_tta()`, `weighted_soft_voting()` from `src_v2.evaluation.ensemble`
- Use `get_classifier_transforms(train=False)` from `src_v2.models`
- Load test dataset via `torchvision.datasets.ImageFolder`
- Hard assert class counts match expected: COVID=452, Normal=1274, Viral_Pneumonia=169, total=1895. Use assertion (exit on mismatch) since any deviation indicates data corruption.
- Set deterministic mode: `torch.manual_seed(42)`, `torch.use_deterministic_algorithms(False)` (keep non-deterministic off since not all ops support it), ensure `shuffle=False` in DataLoader

**3. Evaluate Original Test Set (1,895 images)**
- Run `ensemble_inference_with_tta()` with `use_tta=True`
- Compute soft voting via `weighted_soft_voting()`
- Compute metrics via `sklearn.metrics.classification_report(output_dict=True)`, `confusion_matrix()`, `accuracy_score()`
- Convert all numpy types to native Python (`.item()`, `.tolist()`) for JSON
- Save to `outputs/classifier_cv/final_evaluation_original.json`

**4. Evaluate Cleaned Test Set (1,894 images)**
- Known duplicate: `test/Normal/Normal-817_warped.png` (hash-identical to `train/Normal/Normal-818_warped.png`, found in Phase 1 audit)
- On-the-fly filtering: after creating ImageFolder, filter `dataset.samples` to exclude any sample whose path contains `Normal-817_warped.png`, then update `dataset.targets`
- Assert cleaned count = 1,894
- Run same ensemble+TTA evaluation pipeline
- Save to `outputs/classifier_cv/final_evaluation_cleaned.json`

**5. Deterministic Reproducibility Check**
- Run BOTH evaluations a second time (original and cleaned)
- For each: compute SHA-256 hash of `json.dumps(metrics, sort_keys=True)`
- Assert hash_run1 == hash_run2 for both datasets
- Save reproducibility proof to `outputs/classifier_cv/final_evaluation_reproducibility.json` containing:
  - `original_hash`, `cleaned_hash`, `reproducibility_verified: true/false`
  - `run1_timestamp`, `run2_timestamp`
- Print reproducibility result in Spanish

**6. Range Check + Console Summary**
- Compute improvement over 97.68% baseline for both datasets
- If improvement falls outside +0.5 to +1.0pp: print ADVERTENCIA (warning) but continue — the actual number is what it is (per user decision)
- Print formatted summary table in Spanish with both results side-by-side:
  - Accuracy, F1-macro, F1-weighted, confusion matrix
  - Per-class precision/recall/F1
  - Improvement over baseline
  - Reproducibility status

**7. Update GROUND_TRUTH.json**
- Read existing `GROUND_TRUTH.json`
- Add `gt["classification"]["final_evaluation"]` section following the structure from 05-RESEARCH.md Pattern 3:
  - `description`, `timestamp`, `validated` (today's date)
  - `original_test_set`: all metrics, test_set_size=1895, duplicates_present=1
  - `cleaned_test_set`: all metrics, test_set_size=1894, duplicates_removed=1
  - `reproducibility_verified: true/false`
  - `baseline_improvement_pp` (computed from original)
  - `expected_range_pp: [0.5, 1.0]`
  - `note: "Both results reported equally; duplicate noted for transparency"`
- Update `_metadata.last_updated` to today's date
- Update `_metadata.version` to "2.2.0"
- Write back with `indent=2, ensure_ascii=False`

Important implementation details:
- Use `@torch.no_grad()` decorator AND `model.eval()` (already done by load_ensemble_models)
- Use `num_workers=0` for determinism in DataLoader (avoid multiprocessing non-determinism)
- All JSON numbers must be native Python types (float, int, list), NOT numpy types
- Script should be runnable as: `python scripts/evaluate_final_ensemble_tta.py`
- Use argparse with sensible defaults (config path, output dir, device)
- Import device resolution from `src_v2.cli` or implement simple auto-detection (cuda if available, else cpu)
