  <name>Task 2: Execute ensemble evaluation</name>
  <files>outputs/classifier_cv/ensemble_test_results.json</files>
  <action>
Run the ensemble evaluation CLI command and validate results:

```bash
python -m src_v2 evaluate-classifier-ensemble \
  --config configs/ensemble_classifier.json \
  --output outputs/classifier_cv/ensemble_test_results.json \
  --predictions-csv outputs/classifier_cv/ensemble_predictions.csv \
  --device auto
```

**Expected output:**
1. Console output shows:
   - Model loading progress (5 models)
   - Sanity checks passed
   - Per-fold metrics table
   - Ensemble soft voting results
   - Ensemble hard voting results
   - Comparison with baseline (delta)

2. JSON file contains:
   - `per_fold_metrics`: Array of 5 fold results
   - `ensemble_soft_voting`: Accuracy, F1-macro, F1-weighted, per_class, confusion_matrix
   - `ensemble_hard_voting`: Accuracy, F1-macro, F1-weighted
   - `comparison`: Baseline vs ensemble deltas
   - `timestamp`, `n_folds`, `test_set_size`

3. Predictions CSV contains per-sample breakdown for debugging

**Validation checks after execution:**
1. Verify JSON contains all expected keys
2. Verify `test_set_size` equals 1895
3. Verify per_fold accuracy values match Phase 1 baseline (within 0.001 tolerance)
4. Verify ensemble_soft_voting.accuracy > baseline (improvement expected)
5. Verify confusion_matrix dimensions are 3x3
  </action>
  <verify>
```bash
# Verify output file exists and has correct structure
python -c "
import json
with open('outputs/classifier_cv/ensemble_test_results.json') as f:
    results = json.load(f)

# Check required keys
assert 'per_fold_metrics' in results, 'Missing per_fold_metrics'
assert 'ensemble_soft_voting' in results, 'Missing ensemble_soft_voting'
assert 'ensemble_hard_voting' in results, 'Missing ensemble_hard_voting'
assert 'comparison' in results, 'Missing comparison'

# Check sample count
assert results['test_set_size'] == 1895, f'Wrong sample count: {results[\"test_set_size\"]}'

# Check ensemble improvement
baseline = 0.9768
soft_acc = results['ensemble_soft_voting']['metrics']['accuracy']
delta = soft_acc - baseline
print(f'Baseline: {baseline:.4f}')
print(f'Ensemble soft voting: {soft_acc:.4f}')
print(f'Improvement: {delta:+.4f} ({delta*100:+.2f}%)')

# Verify confusion matrix shape
cm = results['ensemble_soft_voting']['confusion_matrix']
assert len(cm) == 3 and len(cm[0]) == 3, 'Confusion matrix not 3x3'

print('All validation checks passed!')
"
```
