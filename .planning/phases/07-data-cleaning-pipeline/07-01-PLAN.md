**Script 1: `scripts/run_landmark_outlier_detection.py`**

Create a script that detects landmark outliers using the combined metric specified in the locked decision:
- Flag if overall Procrustes distance > 3 sigma OR any single landmark > 4 sigma

Implementation steps:
1. Load predicted landmarks from `outputs/landmark_predictions/session_warping/predictions.npz` (keys: `landmarks` shape (15153, 15, 2), `image_names`, `categories`)
2. Load canonical shape from `outputs/shape_analysis/canonical_shape_gpa.json` (key: `canonical_shape`, a list of [x,y] pairs → np.array shape (15, 2))
3. For each of the 15,153 images, compute:
   - Procrustes distance to canonical shape using `from src_v2.processing.gpa import procrustes_distance, center_shape, scale_shape, align_shape`
   - Per-landmark deviation: center+scale both predicted shape and canonical, align predicted to canonical, then compute Euclidean distance for each of the 15 landmarks. Take the max per-landmark deviation.
4. Use **robust statistics** (per Pitfall 4 in research): compute median and MAD (Median Absolute Deviation) for both Procrustes distances and max per-landmark deviations. Convert MAD to sigma-equivalent via `sigma_equiv = 1.4826 * MAD`. Compute z-scores as `(value - median) / sigma_equiv`.
5. Apply combined flagging: `flagged = (procrustes_z > 3.0) | (per_landmark_z > 4.0)`
6. Save to `outputs/data_cleaning/landmark_outliers.csv` with columns: `image_name, category, procrustes_distance, max_landmark_deviation, procrustes_z, max_landmark_z, flagged, flag_reason`
7. Print summary: total flagged, breakdown by reason (procrustes_only, per_landmark_only, both), percentage flagged

Add argparse with defaults:
- `--predictions`: default `outputs/landmark_predictions/session_warping/predictions.npz`
- `--canonical-shape`: default `outputs/shape_analysis/canonical_shape_gpa.json`
- `--output-dir`: default `outputs/data_cleaning`
- `--procrustes-sigma`: default 3.0
- `--per-landmark-sigma`: default 4.0

**Script 2: `scripts/run_duplicate_resolution.py`**

Create a script that resolves cross-split duplicates by reverse-mapping warped filenames to original image names:

1. Load `outputs/error_forensics/duplicates/cross_split_leakage.csv` (columns: img1, img2, hash_distance, cnn_similarity, split1, split2, class1, class2)
2. Build authoritative warped-to-original mapping by loading `images.csv` from all three splits:
   - `outputs/warped_lung_best/session_warping/{train,val,test}/images.csv`
   - Each has columns: `image_name, category, warped_filename`
   - Build dict: `warped_path → (image_name, category, split)` where `warped_path = f"{split}/{category}/{warped_filename}"`
3. For each cross-split duplicate pair, extract original image names using the mapping
4. Apply resolution strategy (per locked decisions + Claude's discretion → full re-split):
   - Same-class cross-split pairs: keep one instance (alphabetically first by image_name), mark the other as excluded
   - Cross-class pairs (class1 != class2): exclude BOTH images (label ambiguity)
   - Track the duplicate partner and reason for each exclusion
5. Deduplicate the exclusion set (one image may appear in multiple pairs)
6. Save to `outputs/data_cleaning/cross_split_exclusions.csv` with columns: `image_name, category, reason, duplicate_partner, duplicate_partner_category`
7. Save `outputs/data_cleaning/duplicate_resolution_summary.json` with statistics: total pairs processed, same-class pairs, cross-class pairs, unique images excluded, exclusion breakdown by class

Validate: verify that all warped filenames in cross_split_leakage.csv map to an entry in images.csv. Log warnings for any unmapped filenames (research Pitfall 3).
