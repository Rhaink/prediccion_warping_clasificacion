<objective>
Extract out-of-fold probabilities from 5-fold classifier checkpoints and run cleanlab label noise detection.

Purpose: CLN-02 requires detecting potential label noise using cleanlab confident learning on 5-fold CV predictions. The fold checkpoints exist but the per-sample OOF probabilities were NOT saved during training — they must be reconstructed by re-running inference on each fold's validation split. Cleanlab then uses these probabilities to identify label issues.

Output:
- `outputs/data_cleaning/oof_probabilities.npz` — OOF probability matrix (13258, 3), image names, true labels
- `outputs/data_cleaning/cleanlab_issues.csv` — per-sample label issue flags with decision categories
</objective>

**Create `scripts/run_label_noise_detection.py`:**

1. Load OOF probabilities from `outputs/data_cleaning/oof_probabilities.npz`
2. Run cleanlab confident learning:
   ```python
   from cleanlab.filter import find_label_issues

   issue_indices = find_label_issues(
       labels=true_labels,
       pred_probs=pred_probs,
       return_indices_ranked_by='self_confidence',
       filter_by='confident_learning',
   )
   ```

3. Compute per-sample self-confidence:
   ```python
   self_confidence = pred_probs[np.arange(len(true_labels)), true_labels]
   ```

4. Apply decision thresholds (per Claude's discretion in research):
   - `self_confidence < 0.05` AND is_label_issue → `auto_excluded`
   - `0.05 <= self_confidence < 0.40` AND is_label_issue → `manual_review`
   - `self_confidence >= 0.40` AND is_label_issue → `flagged_kept` (cleanlab flagged but confidence not low enough to exclude)
   - NOT is_label_issue → `kept`

5. For each flagged issue, compute the predicted label (argmax of pred_probs) to show what the model thinks the correct label is

6. Save to `outputs/data_cleaning/cleanlab_issues.csv` with columns:
   - `image_name`: original image filename
   - `category`: true label string (COVID/Normal/Viral_Pneumonia)
   - `true_label`: integer label
   - `predicted_label`: integer argmax of OOF probs
   - `predicted_category`: predicted label string
   - `self_confidence`: model's probability of the given label
   - `max_prob`: maximum probability across all classes
   - `is_label_issue`: boolean from cleanlab
   - `cleanlab_rank`: rank among label issues (lower = more likely issue), NaN for non-issues
   - `decision`: auto_excluded / manual_review / flagged_kept / kept

7. Print summary:
   - Total label issues detected by cleanlab
   - Breakdown: auto_excluded, manual_review, flagged_kept, kept
   - Per-class breakdown of label issues
   - Top 10 most likely label errors with their image names, true vs predicted labels, and self-confidence
   - Self-confidence distribution histogram (text-based) for label issues

- `--output-dir`: default `outputs/data_cleaning`
