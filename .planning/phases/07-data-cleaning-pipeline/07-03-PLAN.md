**Script: `scripts/generate_cleaning_manifest.py`**

Create a script that merges all quality signals into a single JSON manifest.

1. **Load all quality signal CSVs:**
   - `outputs/data_cleaning/landmark_outliers.csv` (15,153 rows, all images)
   - `outputs/data_cleaning/cross_split_exclusions.csv` (excluded images only)
   - `outputs/data_cleaning/cleanlab_issues.csv` (~13,258 rows, train+val only)

2. **Build per-image entry.** Start with the landmark outliers CSV (has all 15,153 images). For each image:
   ```python
   entry = {
       "image_name": str,
       "category": str,           # COVID / Normal / Viral_Pneumonia
       "decision": str,           # excluded / kept / review_pending
       "reasons": list[str],      # e.g., ["landmark_outlier", "cross_split_duplicate"]
       "flags": {
           "procrustes_z": float,
           "max_landmark_z": float,
           "is_landmark_outlier": bool,
           "cleanlab_self_confidence": float or null,  # null for test images
           "is_cleanlab_issue": bool or null,
           "cleanlab_decision": str or null,           # auto_excluded / manual_review / flagged_kept / kept
           "predicted_category": str or null,
           "is_cross_split_duplicate": bool,
           "duplicate_partner": str or null,
           "duplicate_partner_category": str or null,
       },
       "review_notes": null       # Filled during manual review
   }
   ```

3. **Determine decision for each image:**
   - Priority order for exclusion: (1) cross-class duplicate → always excluded, (2) landmark outlier (>3/4 sigma) → auto-excluded per locked decision, (3) cleanlab auto_excluded (self_confidence < 0.05) → auto-excluded, (4) cleanlab manual_review → decision = `review_pending`, (5) everything else → `kept`
   - An image can have multiple reasons (e.g., both landmark outlier AND cleanlab issue)
   - Test set images: set cleanlab fields to null, never mark as excluded

4. **Compute summary statistics:**
   ```python
   summary = {
       "total_images_original": 15153,
       "total_flagged": int,
       "total_excluded": int,           # auto-excluded (landmark + duplicate + cleanlab auto)
       "total_review_pending": int,     # needs manual review
       "total_kept": int,
       "excluded_breakdown": {
           "landmark_outlier": int,
           "cross_split_same_class": int,
           "cross_class_duplicate": int,
           "cleanlab_auto_excluded": int,
       },
       "review_pending_breakdown": {
           "cleanlab_manual_review": int,
       },
       "by_class": {class: {excluded: N, review_pending: N, kept: N} for each class},
       "test_set_excluded": 0,  # MUST be 0 — verify
   }
   ```

5. **Validate:**
   - Assert no test set images are excluded (cross-reference with test split in dataset_summary.json)
   - Assert total_excluded + total_review_pending + total_kept = 15,153
   - Log the exclusion rate and warn if > 15% (per locked decision: acceptable to lose 10-15%)

6. **Write manifest:**
   ```python
   manifest = {
       "schema_version": "v1",
       "generated_at": datetime.now().isoformat(),
       "thresholds": {
           "landmark_procrustes_sigma": 3.0,
           "landmark_per_landmark_sigma": 4.0,
           "cleanlab_auto_exclude_self_confidence": 0.05,
           "cleanlab_manual_review_self_confidence": 0.40,
           "phash_threshold": 3,
       },
       "summary": summary,
       "entries": entries,  # list of all 15,153 entries
   }
   json.dump(manifest, open(output_path, 'w'), indent=2)
   ```

7. Print final summary table.

Add argparse with:
- `--landmark-outliers`: default `outputs/data_cleaning/landmark_outliers.csv`
- `--cross-split-exclusions`: default `outputs/data_cleaning/cross_split_exclusions.csv`
- `--cleanlab-issues`: default `outputs/data_cleaning/cleanlab_issues.csv`
- `--dataset-summary`: default `outputs/warped_lung_best/session_warping/dataset_summary.json`
- `--output`: default `outputs/data_cleaning/cleaning_manifest.json`

**Notebook: `notebooks/data_cleaning_review.ipynb`**

Create a Jupyter notebook for manual review of flagged samples (CLN-03). The notebook is gitignored (.gitignore already excludes *.ipynb).

Cell structure:
1. **Setup cell**: imports, load manifest, load original images path
2. **Summary cell**: Display manifest summary, exclusion breakdown, class distribution
3. **Auto-excluded review cell**: Grid visualization of auto-excluded images (landmark outliers + cross-class duplicates + cleanlab auto-excluded), grouped by reason. Show image + flags for spot-checking. No action needed — these are auto-excluded.
4. **Manual review cell**: For `review_pending` items, display each image with:
   - Original image (from `data/dataset/COVID-19_Radiography_Dataset/{category}/images/{image_name}.png`)
   - True label vs predicted label
   - Self-confidence score
   - Landmark outlier scores
   - Accept/Reject buttons (or simple text input: type 'e' to exclude, 'k' to keep)
   - Use ipywidgets for interactive review (consistent with Phase 6 notebook pattern)
5. **Save decisions cell**: Update the manifest JSON with manual review decisions, changing `review_pending` to either `excluded` or `kept`, and populating `review_notes`
6. **Final summary cell**: Show updated statistics after manual review

NOTE: The notebook is a review tool — the script generates the manifest first, then the user runs the notebook to review borderline items. The script stops for user review before proceeding (per Claude's discretion in research: stop for review before re-warping).

   ```python
   ),
   ```

2. **Load exclusion set** early in the function body, after config loading but before the warping loop:
   ```python
   excluded_images = set()
   if exclude_list:
       import json
       with open(exclude_list) as f:
           manifest = json.load(f)
       excluded_images = {
           entry['image_name']
           for entry in manifest['entries']
           if entry['decision'] == 'excluded'
       }
       logger.info(f"Loaded cleaning manifest: excluding {len(excluded_images)} images")
   ```

3. **Apply exclusion** in the warping loop. The generate_dataset function iterates over images from the predictions NPZ. Find where it processes each image and add a skip condition:

   ```python
   # Before processing each image in the loop:
   ```
