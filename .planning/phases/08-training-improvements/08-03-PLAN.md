**Step 1: Identify best individual ablation**

Read all 4 results from Plan 02 and find the experiment with highest val_f1_macro_mean:
```python
import json
experiments = {
    'baseline': 'outputs/classifier_cv_cleaned_baseline/cross_validation_results.json',
    'focal': 'outputs/classifier_cv_focal/cross_validation_results.json',
    'mining': 'outputs/classifier_cv_mining/cross_validation_results.json',
    'curriculum': 'outputs/classifier_cv_curriculum/cross_validation_results.json',
}
best_name = None
best_f1 = 0.0
for name, path in experiments.items():
    with open(path) as f:
        data = json.load(f)
    f1 = data['summary']['val_f1_macro_mean']
    if f1 > best_f1:
        best_f1 = f1
        best_name = name
```

The best individual ablation's fold_01/best_classifier.pt will be used as finetune_from.

**Step 2: Update cv_combined.json**

Add `"finetune_from"` key pointing to the best ablation's fold 1 checkpoint. For example, if focal is best:
```json
{
  ...,
  "finetune_from": "outputs/classifier_cv_focal/fold_01/best_classifier.pt"
}
```

Note: Using fold_01 checkpoint for all folds means each fold starts from the same pretrained weights (from focal fold 1). This is a form of transfer learning — the combined training loop fine-tunes from this starting point for each fold independently.

**Step 3: Run combined model**
```bash
source .venv/bin/activate
python -m src_v2 cross-validate-classifier --config configs/cv_combined.json --device cuda
```

Monitor logs for:
- "Fine-tuning from: ..." (confirms checkpoint loading)
- "Using FocalLoss (gamma=2.0)" (confirms focal loss)
- "Mining: X/Y samples matched OOF" (confirms mining)
- "Curriculum: stage N, M samples" (confirms curriculum stages)

After completion, extract metrics from `outputs/classifier_cv_combined/cross_validation_results.json`.
