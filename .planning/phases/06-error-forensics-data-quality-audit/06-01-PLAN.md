**src_v2/evaluation/error_analysis.py** - Error categorization and pipeline failure tracing:

1. `load_error_samples(predictions_csv, dataset_dir, warped_dir, predictions_npz)` -> DataFrame
   - Load `outputs/classifier_cv/ensemble_predictions_tta.csv` (1895 test samples, columns: sample_idx, true_label, soft_prediction, hard_prediction, soft_correct, hard_correct)
   - Filter to misclassified samples where `soft_correct == 0` (should be 33 errors)
   - For each error, resolve file paths: original image from `data/dataset/COVID-19_Radiography_Dataset/{class}/`, warped image from `outputs/warped_lung_best/session_warping/test/{class}/`
   - Load per-fold predictions from `outputs/classifier_cv/fold_0{N}/test_results.json` to get fold-level agreement
   - Load landmark predictions from `outputs/landmark_predictions/session_warping/predictions.npz` to get per-sample landmark coordinates
   - Map numeric labels to class names using CATEGORIES from constants.py (0=COVID, 1=Normal, 2=Viral_Pneumonia)
   - Return enriched DataFrame with columns: sample_idx, true_class, predicted_class, confidence, margin, fold_agreement, landmark_coords, original_path, warped_path

2. `categorize_errors(error_df)` -> DataFrame with category columns
   - Use confidence x fold agreement matrix to assign categories:
     - UNANIMOUS_HIGH_CONF: all folds agree wrong + confidence > 0.9 -> likely label noise -> recoverability: "fixable"
     - UNANIMOUS_LOW_CONF: all folds agree wrong + confidence < 0.6 -> hard example -> recoverability: "partially_fixable"
     - HIGH_CONF_ERROR: majority agree wrong + confidence > 0.9 -> systematic bias -> recoverability: "fixable"
     - SPLIT_DECISION: folds disagree (agreement < 0.6) -> near boundary -> recoverability: "partially_fixable"
     - MODERATE: everything else -> model limitation -> recoverability: "inherent"
   - Add columns: category, interpretation, likely_cause, recoverability

3. `trace_pipeline_failures(error_df, canonical_shape_path)` -> DataFrame with pipeline trace columns
   - Load canonical shape from `outputs/shape_analysis/canonical_shape.npz`
   - For each error, compute landmark quality: per-sample mean pixel error vs dataset average (3.61 px)
   - Compute warp quality: fill_rate of the warped image (non-black pixel percentage using compute_fill_rate from warp.py)
   - Classify failure origin:
     - "bad_landmarks": landmark error > 2x dataset mean (>7.22 px)
     - "bad_warp": fill_rate < 0.85 or landmark error > 1.5x mean
     - "ambiguous_image": good landmarks + good warp but low confidence
     - "suspect_label_noise": good landmarks + good warp + high confidence wrong prediction
   - Add columns: landmark_error_px, warp_fill_rate, failure_origin

Note: The ensemble_predictions_tta.csv has numeric labels (0,1,2) not class names. The fold test_results.json files contain per-fold predictions. You need to cross-reference sample indices across these files to compute fold agreement. If per-fold data is not easily available at sample level, compute fold agreement from the cross_validation_test_results.json or derive it from the fold directories.

   - Label landmarks with L1-L15 names from LANDMARK_NAMES

2. `visualize_pipeline_trace(original_img, landmarks, warped_img, true_class, pred_class, probs, category, failure_origin, output_path)` -> None

     - Panel 1: Original X-ray (grayscale)
     - Panel 2: Landmarks overlay on original (with Delaunay triangulation)
     - Panel 3: Warped image (grayscale)
     - Panel 4: Classification result text + probability bar chart (3 horizontal bars for COVID/Normal/Viral_Pneumonia)
   - Title: f"True: {true_class} | Pred: {pred_class} | {category} | {failure_origin}"
   - Save at 150 DPI, bbox_inches='tight'

3. `create_overview_grid(error_samples, output_path, ncols=6)` -> None
   - Create compact grid of all 33 errors: show warped image thumbnails in grid layout
   - Each thumbnail annotated with: true -> predicted class, confidence score
   - Color-code border: red for high confidence errors, orange for low margin, gray for moderate
   - Group by confusion pair (COVID->Normal, Normal->COVID, etc.) per user decision on "most informative" grouping
   - Title: "Resumen de 33 errores de clasificacion - Ensemble+TTA (98.26%)"
   - Save at 300 DPI for thesis quality

Follow existing code conventions: PEP 8, 100-char line limit, type hints, Google-style docstrings. Use matplotlib with 'Agg' backend for non-interactive generation.
