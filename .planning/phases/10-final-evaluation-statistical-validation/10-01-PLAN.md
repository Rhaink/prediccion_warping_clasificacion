Then create `scripts/evaluate_final_phase10.py` — a comprehensive evaluation script that:

**Part A: Ensemble Evaluation (all 4 models, with and without TTA)**
1. For each of the 4 configs, load the 5 fold models using `load_ensemble_models()`
2. Load the test dataset from `data_dir/test` using `torchvision.datasets.ImageFolder`
3. Run `ensemble_inference_with_tta()` for TTA evaluation
4. Run without TTA (set `use_tta=False`) for no-TTA baseline
5. Apply `weighted_soft_voting()` to get ensemble predictions
6. Save per-sample predictions CSV to `outputs/phase10/predictions/{name}_predictions.csv` with columns: `sample_idx, image_path, true_label, soft_prediction, confidence, prob_COVID, prob_Normal, prob_VP`
7. Compute metrics using `sklearn.metrics.classification_report` (precision, recall, F1 per class + macro)
8. Save ensemble results JSON to `outputs/phase10/ensemble_results/{name}_results.json`

**Sanity check:** v1.0 TTA accuracy must be within 0.001pp of 98.26% (the known baseline). If not, abort and report the mismatch.

**Part B: Statistical Validation**
For each of the 3 comparisons (cleaned vs v1.0, curriculum vs v1.0, elastic+curriculum vs v1.0), using TTA predictions:

1. **McNemar's test (with Yates continuity correction):**
   - Load paired CSVs, align by sample_idx
   - Compute b (regressions: v1.0 correct AND improved wrong) and c (improvements: v1.0 wrong AND improved correct)
   - Statistic = (|b - c| - 1)^2 / (b + c)
   - p_value = 1 - chi2.cdf(statistic, df=1) using `scipy.stats.chi2`

2. **Bootstrap 95% CI (10,000 iterations, seed=42):**
   - For each model: resample correct/incorrect array with replacement, compute accuracy
   - Report mean, ci_low (2.5th percentile), ci_high (97.5th percentile)

3. **DeLong AUC comparison (bootstrap-based):**
   - Compute per-class OvR AUC using `sklearn.metrics.roc_auc_score(multi_class='ovr')`
   - Bootstrap CI for AUC (10,000 iterations) as a surrogate for analytic DeLong
   - Report per-class OvR AUC and macro AUC with 95% CI for each model

4. **Holm-Bonferroni multiple comparison correction:**
   - Sort 3 McNemar p-values ascending
   - Corrected threshold for rank i (1-indexed): alpha / (3 - i + 1)
   - Report both raw and corrected significance

5. **Regression guardrail (EVL-05):**
   - Count b (regressions) for each comparison
   - Pass if b <= 5, fail otherwise
   - If any model fails, print WARNING but do not abort (soft report per Claude's discretion)
