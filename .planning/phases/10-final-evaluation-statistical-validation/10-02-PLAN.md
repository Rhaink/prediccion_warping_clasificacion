Create `scripts/generate_case_analysis_phase10.py` that performs case-level impact analysis (EVL-02) for the elastic+curriculum model vs v1.0 baseline.

**Categorization (3 categories per Claude's discretion):**
- **Mejorado (Improved):** v1.0 wrong AND elastic+curriculum correct
- **Regresado (Regressed):** v1.0 correct AND elastic+curriculum wrong
- **Neutral:** Same prediction outcome (both correct or both wrong)

**For each changed case, record:**
- sample_idx, image_path, true_label
- v1.0 prediction + confidence (max softmax probability)
- elastic+curriculum prediction + confidence
- Category (mejorado/regresado)

**Image Grid Generation:**
For improved and regressed cases:
1. Load the actual X-ray image from `outputs/warped_cleaned/session_warping/test/{class}/{filename}`
2. Create a matplotlib grid (up to 4x4 = 16 images per grid, or fewer if less cases exist)
3. Each cell shows: the X-ray image, title with "Real: {true_label}", subtitle with "v1.0: {pred} ({conf:.1%}) -> v1.1: {pred} ({conf:.1%})"
4. Green border for improved cases, red border for regressed cases
5. File: `case_grid_improved.png` and `case_grid_regressed.png`

**Cross-reference with Phase 6 (per Claude's discretion):**
If `outputs/error_forensics/misclassified_test_images.json` or similar Phase 6 artifact exists, cross-reference regressed cases to check if they were in the original 33 misclassified set. Add this info to the output JSON.

- `outputs/phase10/case_analysis/case_grid_regressed.png` — Image grid of regressed cases (if any exist)
- Also generate grids for cleaned_vs_v1 and curriculum_vs_v1 if there are meaningful changes
