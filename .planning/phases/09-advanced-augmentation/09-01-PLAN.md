**Step 2: Extend get_classifier_transforms() in src_v2/models/classifier.py**

Add an `AlbumentationsWrapper` class and modify `get_classifier_transforms()` to accept augmentation parameters:

```python
def get_classifier_transforms(
    train: bool = False,
    img_size: int = 224,
    use_elastic: bool = False,
    elastic_alpha: float = 1.0,
    elastic_sigma: float = 30.0,
    elastic_p: float = 0.5,
    use_grid_distortion: bool = False,
    grid_distort_limit: float = 0.1,
    grid_distort_p: float = 0.5,
    use_pixel_aug: bool = False,
) -> transforms.Compose:
```

When `train=True` and any augmentation flag is set:
1. Build an `albumentations.Compose` with the requested transforms
2. Insert `AlbumentationsWrapper(albu_compose)` AFTER `Resize` but BEFORE `RandomHorizontalFlip` in the train transform list
3. Use `border_mode=0` (BORDER_CONSTANT) and `fill=0.0` for all spatial transforms (critical: warped images have black background)
4. ElasticTransform: `A.ElasticTransform(alpha=elastic_alpha, sigma=elastic_sigma, p=elastic_p, border_mode=0, fill=0.0)`
5. GridDistortion: `A.GridDistortion(num_steps=5, distort_limit=grid_distort_limit, p=grid_distort_p, border_mode=0, fill=0.0, normalized=True)`
6. Pixel augmentations (when use_pixel_aug=True): `A.RandomBrightnessContrast(brightness_limit=0.15, contrast_limit=0.15, p=0.4)` + `A.GaussNoise(std_range=(0.01, 0.03), mean_range=(0, 0), p=0.3)`
7. When `train=False`, NO augmentation flags are applied (eval transform stays unchanged)

The `AlbumentationsWrapper` class converts PIL -> numpy -> albumentations -> PIL:
```python
class AlbumentationsWrapper:
    """Wraps albumentations Compose for use in torchvision Compose pipeline."""
    def __init__(self, albu_transform):
        self.transform = albu_transform
    def __call__(self, pil_img):
        import numpy as np
        img_np = np.array(pil_img)
        augmented = self.transform(image=img_np)['image']
        return Image.fromarray(augmented)
```

Add `import albumentations as A` at the top of the file (conditional import is not needed since albumentations will be in requirements.txt).

Inside the training batch loop (around line 3631-3644), insert MixUp/CutMix application AFTER moving to device but BEFORE the forward pass:
```python
for inputs, labels_batch in train_loader:
    inputs = inputs.to(torch_device)
    labels_batch = labels_batch.to(torch_device)

    # Apply batch-level mixing (training only)
    if mixup_fn is not None:
        inputs, labels_batch = mixup_fn(inputs, labels_batch)
        # labels_batch is now (B, num_classes) float32 — CE accepts this natively

    optimizer.zero_grad()
    outputs = model(inputs)
    loss = criterion(outputs, labels_batch)
```

**Step 1: Create scripts/preview_augmentations.py**

This script is the visual validation gate. It generates augmentation preview grids and SSIM metrics for user review.

Script structure:
1. Parse args: `--data-dir` (default: `outputs/warped_cleaned/session_warping`), `--output-dir` (default: `outputs/augmentation_previews`), `--n-samples` (default: 5 per class)
2. Load N_SAMPLES random images from each class (COVID, Normal, Viral_Pneumonia) from train split
3. For each augmentation type, apply it with p=1.0 (forced, for preview visibility) to all sample images:
   - ElasticTransform(alpha=1.0, sigma=30.0, border_mode=0, fill=0.0)
   - ElasticTransform(alpha=20.0, sigma=30.0, border_mode=0, fill=0.0) — moderate variant for comparison
   - GridDistortion(num_steps=5, distort_limit=0.1, border_mode=0, fill=0.0)
   - RandomBrightnessContrast(brightness_limit=0.15, contrast_limit=0.15) + GaussNoise(std_range=(0.01, 0.03))
   - MixUp preview: blend pairs of images from different classes (lambda=0.6 for visibility: 60% img_A + 40% img_B)
   - CutMix preview: paste rectangular patch from one class image onto another (simulate alpha=0.2 -> small patches)
4. Compute SSIM for each pair (original vs augmented) using `skimage.metrics.structural_similarity(orig, aug, channel_axis=-1, data_range=255)`
5. Generate visual grids (matplotlib):
   - One grid per augmentation type: rows = samples (one per class), columns = [Original, Augmented, Difference Map]
   - Title includes augmentation name and mean SSIM
   - Save as PNG at 200 DPI
6. Print SSIM summary table to stdout:
   ```
   Augmentation             Mean SSIM    Std SSIM    Status
   ElasticTransform(1,30)   0.XXXX       0.XXXX      PASS/REVIEW
   ElasticTransform(20,30)  0.XXXX       0.XXXX      PASS/REVIEW
   GridDistortion(0.1)      0.XXXX       0.XXXX      PASS/REVIEW
   PixelAug                 0.XXXX       0.XXXX      PASS/REVIEW
   MixUp(lambda=0.6)        0.XXXX       0.XXXX      INFO
   CutMix(alpha=0.2)        0.XXXX       0.XXXX      INFO
   ```
   Status: PASS if SSIM > 0.95, REVIEW if SSIM between 0.85-0.95, FAIL if < 0.85. MixUp/CutMix always show INFO (SSIM is expected to be lower due to content mixing).
7. Save SSIM results as JSON: `outputs/augmentation_previews/ssim_results.json`

The script does NO training — it is purely diagnostic and intended for the visual gate checkpoint.
